# Tappy Plane

A Flappy Bird-style game developed in **Godot** using **C#**, following a Udemy course as a guided learning project.

The project recreates the core gameplay loop of Flappy Bird while providing hands-on experience with Godot's game development workflow and C# scripting.

## Features

- Flappy Bird-style side-scrolling gameplay
- Player-controlled movement and jumping
- Procedurally generated pipe obstacles
- Collision detection
- Score tracking
- Game-over and restart functionality
- 2D game development using Godot
- C# scripting

## Technologies

- **Godot Engine**
- **C# / .NET**
- **Git / GitHub**

## Getting Started

### Prerequisites

- [Godot Engine](https://godotengine.org/) with C#/.NET support
- .NET SDK compatible with the version of Godot being used
- Git, if cloning the repository

### Running the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/apaquette/Tappy.git
   ```

2. Open the project in the Godot editor.

3. Allow Godot to import and build the C# project if prompted.

4. Run the project using the **Play** button or the appropriate Godot run command.

## Controls

| Action | Input |
|---|---|
| Flap / Jump | `Space` |
| Quit | `Esc` |

## Learning Context

This project was created while following the **Learn 2D Game Development: Godot 4 & C# from scratch** on Udemy. It is primarily intended as a learning exercise for becoming familiar with:

- Godot's scene and node architecture
- C# scripting within Godot
- 2D physics and collision detection
- Game state management
- Player input
- Basic procedural gameplay
- Score and UI systems
- Structuring a small game project
